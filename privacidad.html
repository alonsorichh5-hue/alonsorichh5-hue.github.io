Política de privacidad

Última actualización: 19 de noviembre de 2026.

1. Quién usa la aplicación

Shorts Autopilot es una aplicación interna que usa solamente su dueño para gestionar su propio canal de YouTube. No tiene usuarios externos ni recoge datos de visitantes.

2. Datos de Google a los que accede

Con la autorización del dueño del canal, mediante OAuth de Google, la aplicación accede a:

  • YouTube Data API v3: subir y programar videos en el canal del dueño, y leer la lista de videos del propio canal para evitar duplicados.
  • YouTube Analytics API: leer estadísticas agregadas de los videos del propio canal (vistas, duración media vista, porcentaje visto, me gusta y suscriptores ganados).
  • Búsqueda pública de YouTube: títulos y estadísticas públicas de Shorts para medir qué temas interesan al público.

3. Cómo se usan y guardan

Los datos se usan solo para publicar los videos del dueño y para decidir qué formatos y temas funcionan mejor. Se guardan en un repositorio privado de GitHub del dueño. El token de acceso se guarda cifrado como secreto de GitHub Actions. No se venden, no se comparten con terceros y no se usan con fines publicitarios.

El uso de la información recibida de las APIs de Google cumple la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos los requisitos de uso limitado. La aplicación también se rige por las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

4. Cómo revocar el acceso

El acceso puede revocarse en cualquier momento desde la configuración de seguridad de la cuenta de Google. Al revocarlo, la aplicación deja de funcionar y se pueden borrar sus datos eliminando el repositorio privado.
